For your feedback you wanted some help with the social media icons, now I will be honest I am not too experienced with wordpress but here is my best shot. First is I would try and get something to appear in that spot, it doesn't have to be the icons just any image there. Try different sizes of images, colors of images, and image types (png, jpeg, etc). If you still find your unable to get any image visible try getting words visible where the icons should be. Second is file pathing, where if the page cannot find the file then fails. I have found that alot of webpages need images in the save folder as the webpage to load properly as going above the folder makes it near impossible to find.
